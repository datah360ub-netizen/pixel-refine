🚀 Getting Started

1. Download the Project

Download or clone the project files to your computer.

2. Keep the Files Together

Ensure that "index.html", "style.css", and "script.js" are located in the same folder.

3. Run Locally

Open "index.html" in a modern web browser to preview the website.

Some functions may require a local development server or external services.

4. Deploy with GitHub Pages

1. Create or open your GitHub repository.
2. Upload "index.html", "style.css", "script.js", and "README.md" to the repository root.
3. Open Settings → Pages.
4. Select the appropriate deployment branch and root folder.
5. Save the settings and wait for deployment to finish.
6. Open the published website using the URL provided by GitHub Pages.

⚙️ Tool Requirements

Browser-compatible image operations can be performed locally when implemented using supported browser APIs or JavaScript libraries.

The following advanced features may require a real backend or third-party API:

- AI Background Remover
- Advanced AI Image Upscaling
- Photo Colorization using AI
- Advanced Photo Enhancement
- Reliable Word-to-PDF and PDF-to-Word conversion
- Server-based PDF processing

Buttons that depend on unavailable services should clearly explain what needs to be connected instead of pretending the operation succeeded.

---

🔐 Security & Payments

The website should use a secure backend for production account and payment features.

- Never store passwords as plain text.
- Never trust frontend JavaScript to authorize payments or award purchased coins.
- Verify payments on the server before activating subscriptions.
- Validate coin deductions and rewards on the server.
- Enforce daily reward limits using server-side dates and account records.
- Protect account information and uploaded files.
- Use secure authentication and appropriate session management.
- Provide a privacy policy and cookie notice appropriate to the services used.

Important: GitHub Pages provides static hosting only. It does not run a custom backend server. Authentication, persistent accounts, secure coin balances, subscription management, and payment verification require suitable external services or a separate backend.

---

🍪 Privacy & Cookies

Pixel Refine should clearly explain its use of cookies and similar technologies.

Depending on the services integrated, users may need options to accept, reject, or customize non-essential cookies. The privacy notice should describe how account data, uploaded files, and analytics information are handled.
