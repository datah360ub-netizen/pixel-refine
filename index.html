Is Pixel Refine free?

The starter version is free. Premium/API-powered processing can be connected later.

Do you store uploaded files?

The frontend is designed to support browser-side processing for suitable tools. Server/API tools can be configured with explicit privacy policies.

Can more tools be added?

Yes. The tool registry is structured so additional image, PDF and AI tools can be added without redesigning the homepage.
