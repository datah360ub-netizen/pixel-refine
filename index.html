GOOD TO KNOW

Frequently asked questions.

Quick answers before you get started.

Is Pixel Refine free to use?

Pixel Refine includes a free-plan concept. Actual tool availability and daily coin limits depend on the connected JavaScript and backend.

Are all tools powered by AI?

No. Some image tools can work directly in the browser. Advanced AI features need a suitable model or processing service.

Are my uploaded files stored?

File handling depends on how each tool is built. Browser-based processing may keep files on your device, while server-based processing needs a clear privacy policy.

Does it work on mobile and desktop?

The website is designed for responsive layouts. The final appearance should be checked on real mobile and desktop screen sizes.
